# Result: Import Academic Collocations (Pearson 2025)

> Date: 2026-06-11 — see prompt at `src/doc/prompts/import-academic-collocations.md`.

## Scope

Turned Pearson's Academic Collocation List (PTE v2/2025) into **30 ready-to-import
JSON files** for the app's deck-import flow. Together they hold **2,468** fully
enriched flashcards (English collocation + General-American IPA + natural
Vietnamese meaning + exactly 3 EN/VI example sentences), one deck:
`Academic Collocations (Pearson 2025)`. No app code or DB was modified — the user
imports the files via the existing `POST /api/decks/import` UI.

## Files changed (all new, none in app source except the two doc files)

Under `collocations-import/` (repo root, data/build artifacts — not app code):

- `parse_pdf.py` — the task's original PDF parser (kept verbatim). Undercounts
  (2,461) because of wrapped lines and a `component` noise filter.
- `build_spine.py` — robust replacement parser. POS-aware tokenizer (splits at
  `n/v/adj/adv/vpp` so two items on one physical line both survive), merges
  wrapped continuation lines, restores articles/prepositions, de-dups the
  `take on/up the role of` seam. Produces the authoritative spine.
- `collocations.json` — spine of **2,468** entries `{id, comp1, pos1, comp2,
  pos2, pos_label, english, ipa:"", meaning_vi:"", examples:[]}`.
- `colloc-01.json` … `colloc-30.json` — 30 import files (export-payload shape:
  `{version, exported_at, deck, cards}`). File 01 = 82 cards (hand-written);
  02–09 = 83 each; 10–30 = 82 each.
- `validate.mjs` — re-runnable verifier (counts, dupes, field/IPA/example checks,
  1-to-1 order match vs spine).
- `src/doc/prompts/import-academic-collocations.md`, this result file.

## Key decisions

- **Deck-import route, not direct DB writes.** Reuses the validated
  `POST /api/decks/import` (dedup by `english`, SRS reset to `new`). User imports
  in-browser, so no auth/user_id handling or D1 access was needed from here.
- **30 numbered files**, imported sequentially: file 01 with mode "Tạo bộ mới"
  (creates the deck), files 02–30 with mode "Insert vào bộ có sẵn".
- **Articles restored** in headwords (`achieve a goal`, `allow access to`,
  `affect the development of`) per the user's choice, with matching IPA
  (weak-form function words).
- **One card per Component-II item** (e.g. `academic` → 19 cards, `achieve (an)`
  → `achieve an objective` + `achieve an outcome`).
- **Enrichment split**: ids 1–82 hand-written (file 01); ids 83–2468 generated by
  a 29-agent parallel workflow under one shared GenAm-IPA + meaning + 3-example
  rulebook; agents copied `english`/`part_of_speech` verbatim from the spine and
  self-validated each file with `node`.

## Deviations from prompt

- **Total is 2,468, not 2,469.** The source list numbers entries up to 2,469 but
  the `significant (adj)` group jumps 2061 → 2088 while containing only 26 items
  (confirmed against the PDF text layer, page 34). Pearson skipped one number; no
  card was fabricated to reach 2,469. Deck label set to "2,468 collocations".
- `parse_pdf.py` left unchanged (kept as the user provided it); the real spine is
  built by the new `build_spine.py` because the original drops 8 collocations
  (7 × `component`, 1 × the `significant` numbering skip).

## Verification

`node collocations-import/validate.mjs` → **ALL CHECKS PASSED**:
- 2,468 cards across the 30 files (matches spine).
- Exact 1-to-1 order match against the spine — 0 missing, 0 extra, 0 reordered.
- 0 duplicate `english` (case-insensitive) across all 30 files.
- Every card has english + vietnamese + ipa + part_of_speech + exactly 3
  `{en, vi}` examples; 0 IPA-format errors; single consistent deck name.
- Quality spot-check confirmed heteronym IPA (conduct(v) `/kənˈdʌkt/`,
  record(v) `/rɪˈkɔːrd/`, present(v) `/prɪˈzent/`, use(v) `/juːz/`), GenAm
  vowels, and natural Vietnamese/examples.

**Not tested:** end-to-end import into a running app (the user does this); audio
is intentionally absent (can be fetched later via the deck's refresh-audio).

## Follow-ups / known issues

- Import order matters: do file 01 first as a **new** deck, then 02–30 into the
  **existing** deck. Re-importing any file is safe (route skips `english` dupes).
- A few faithful-but-awkward headwords from the source survive (e.g.
  `affect the development of`, `high/er frequency`). Can be hand-tweaked if
  desired.
- `/tmp/colloc-venv` (pdfplumber) is a throwaway virtualenv; safe to delete.
